# Personalização do Template Master

Para criar um novo projeto, altere primeiro `siteConfig.ts` e depois substitua os dados em `src/data/products.ts` e `src/data/guide.ts`.

## Identidade
- `brand`: nome, logo, favicon, tagline e descrição.
- `theme`: cores principal e secundária.
- `contact`: WhatsApp, telefone, e-mail e mensagem.
- `social`: Instagram.
- `seo`: título, descrição e domínio.

## Home
- `announcement`: faixa animada.
- `hero`: banners, textos e CTAs.
- `navigation`: menu.
- `home.benefits`: benefícios.
- `home.categories`: categorias.
- `home.why`: diferenciais.
- `home.guide`: guia/conteúdo.
- `home.reviews`: prova social.
- `home.stores`: lojas físicas.
- `home.shopBySize`: módulo opcional.
- `home.firstVisit`: popup opcional.

O layout, as animações, os componentes e a responsividade ficam no template e não precisam ser refeitos para cada cliente.
